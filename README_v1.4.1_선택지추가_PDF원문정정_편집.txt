HEON ARCHIVE v1.4.1 — 선택지 추가 및 PDF 정정 박스 편집·삭제 (2026-11-22)

[이번 업데이트]
1) 마스터 계정(ssk8181)에서 "문항 수정 → 선택지 수정"을 누르면
   변경사항 저장 | ＋ 선택지 추가 | 취소 순으로 버튼이 표시됩니다.
   기존 번호와 정답을 유지하며, 1~10번 내에서 최대 10개까지 선택지를 추가할 수 있습니다.
   새 선택지는 내용이 비어 있으면 저장되지 않으며 회원에게도 게시됩니다.

2) 마스터 계정의 "해설 수정 · 강의안"에 "나머지 보기 · PDF 원문 정정 수정" 영역을 추가했습니다.
   기존 텍스트를 편집하거나 "이 박스 삭제"를 눌러 표시를 삭제할 수 있습니다.
   삭제는 확인을 거쳐 "모든 변경사항 저장"을 눌러야 실제 반영됩니다.
   저장 전에는 "삭제 취소"가 가능합니다. 삭제 이후에도 새 텍스트를 입력해 복원할 수 있습니다.
   기존 PDF 원본 파일 및 강의안/선택지별 해설은 삭제되지 않습니다.
   정정 박스만 비표시됩니다. 수정 전 버전은 Supabase 질문 콘텐츠 이력에 남습니다.

3) 기존 변경 내역, 회원 전용 인증, 해설 2단 배치, 강의안 이미지 확대, OCR 경고 제거,
   북마크 옆 관리자 문항 수정 버튼, 선택지별 해설 저장 수정 등이 그대로 유지됩니다.
